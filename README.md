# Копилка 400к

Личное приложение для подушки безопасности: корзины под акционные ставки, сроки и напоминания, пополнения, квесты месяца, уровни и достижения. Работает в браузере на телефоне и компьютере, ставится на главный экран как приложение. Данные синхронизируются через твой проект Firebase, вход через личный Google.

Всё бесплатно: GitHub Pages раздаёт файлы, Firebase хранит данные (тариф Spark, без карты).

## Попробовать прямо сейчас (локально)

```sh
cd ~/Desktop/personal/kopilka
python3 -m http.server 8765
```

Открой http://127.0.0.1:8765. Пока `firebase-config.js` пустой, приложение работает в локальном режиме: данные хранятся только в этом браузере.

## Настройка один раз (~15 минут)

### 1. Firebase: проект и база

1. Зайди на https://console.firebase.google.com под **личным** Google-аккаунтом → **Create a project** → имя `kopilka` → Google Analytics можно выключить.
2. **Build → Firestore Database → Create database** → регион `eur3 (europe-west)` → **Start in production mode**.
3. Вкладка **Rules** → вставь содержимое `firestore.rules`, замени `ТВОЯ_ПОЧТА@gmail.com` на свою почту → **Publish**. Теперь данные может читать и менять только этот аккаунт.

### 2. Firebase: вход через Google

1. **Build → Authentication → Get started → Sign-in method → Google → Enable** → выбери почту поддержки → **Save**.
2. Там же **Settings → Authorized domains → Add domain** → добавь `ТВОЙ_ЛОГИН.github.io` (после шага 4 будет понятно, какой именно).

### 3. Firebase: конфиг приложения

1. **Project settings** (шестерёнка) → **Your apps** → иконка `</>` (Web) → имя `kopilka` → **Register app**. Firebase Hosting не нужен.
2. Скопируй из показанного `firebaseConfig` поля `apiKey`, `authDomain`, `projectId`, `appId` в `firebase-config.js`.

Этот конфиг не секретный, его можно класть в публичный репозиторий: доступ к данным защищают правила из шага 1.

### 4. GitHub Pages: хостинг

1. На https://github.com под личным аккаунтом → **New repository** → имя `kopilka` → **Public** (бесплатные Pages только для публичных репозиториев; в коде нет ничего личного, данные лежат в Firebase).
2. Залей файлы:
   ```sh
   cd ~/Desktop/personal/kopilka
   git init -b main
   git add .
   git commit -m "Копилка 400к"
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/kopilka.git
   git push -u origin main
   ```
3. Репозиторий → **Settings → Pages** → Source: **Deploy from a branch** → `main` / `/ (root)` → **Save**. Через минуту приложение будет на `https://ТВОЙ_ЛОГИН.github.io/kopilka/`.

### 5. Установить на телефон

- **iPhone:** открой ссылку в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** открой в Chrome → меню ⋮ → «Установить приложение».

Первый раз войди через Google. На компьютере открой ту же ссылку и войди тем же аккаунтом: данные будут одни и те же.

## Как пользоваться

- **+ Пополнить** — каждый раз, когда кладёшь деньги в копилку (зарплата, премия).
- **+ Корзина** или **Открыть корзину** у предложения на вкладке «Ставки» — когда открыл счёт или вклад. Сразу нажми **🔔 Google** (событие в Google Календаре за 2 дня до конца ставки) или **📅 .ics** (файл для любого календаря, с напоминанием).
- **Забрать** — когда закрыл корзину: впиши, сколько пришло процентов. Деньги вернутся в «Свободные», доход пойдёт в «Заработано».
- **Пора действовать** — сюда сами поднимаются корзины, у которых до конца ставки 7 дней или меньше.
- **Квесты месяца**, **серия пополнений**, **уровни** и **достижения** считаются сами.
- **Ещё → Скачать бэкап** — раз в месяц сохраняй файл на всякий случай.

## Обновления

Поменял файлы → `git add . && git commit -m "…" && git push`. GitHub Pages обновит сайт за минуту, приложение подтянет новую версию при следующем открытии.

## Файлы

| Файл | Что это |
|---|---|
| `index.html`, `style.css`, `app.js` | Интерфейс и логика |
| `store.js` | Хранилище: Firebase или локальное |
| `firebase-config.js` | Настройки твоего проекта Firebase |
| `firestore.rules` | Правила доступа к данным (вставляются в консоли Firebase) |
| `manifest.webmanifest`, `sw.js`, `icon*` | Установка на телефон и офлайн-режим |
